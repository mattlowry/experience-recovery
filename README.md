# Experience Recovery

Website for Experience Recovery Detox & Residential, LLC — in-network detox and residential treatment in Santa Ana, Orange County.

## Stack

- Astro (static)
- Netlify (hosting, forms, redirects)
- Existing campus photographs in `public/images/campus/`

## Local

```bash
npm install
npm run dev
```

Build: `npm run build`

## Forms

Netlify form name: `admissions`. Detection file: `public/__forms.html`. Enable Forms in the Netlify UI after the first deploy.
